우리 아기의 기록, 보호자가 선택하여 보관합니다.

첫백일+은 성인 보호자가 사용하는 육아 기록 앱입니다. 혼자 기록할 때 기록은 기기에 보관합니다. ‘함께 기록’을 선택하면 돌봄 기록을 암호화하여 서버에 저장하고 직접 승인한 보호자와 주고받습니다. 일기와 사진은 가족에게 자동 공유하지 않습니다. 광고·광고 추적·사용자 행동 분석 SDK를 사용하지 않습니다.

1. 기기에서 처리하는 정보

보호자가 입력한 아기 이름 또는 별명·생년월일·성별, 체중·수유 방식과 변경 이력, 수유량·수유 종류·수유/수면/트림/활동의 시작과 종료, 소변·대변·체온·투약, 일정·완료 상태, 입력·수정 시각과 변경 이력을 기록 표시, 합계·평균·리포트, 월령별 안내에 사용합니다. 출석·선물·캐릭터·알림 설정·하루 분유 기준량도 보관합니다. 앱은 건강 상태를 진단하거나 투약량을 결정하지 않습니다.

돌봄 기록과 가족 연결 정보는 앱 전용 저장소에 AES-GCM으로 암호화하고 Android Keystore로 암호화 키를 보호합니다. 시스템 자동 백업·자동 기기 이전에서 앱 저장소를 제외합니다. 사용자가 내보낸 기록 백업이나 리포트는 선택한 저장 위치에 남으며 자동 삭제되지 않습니다.

2. 선택한 보호자와 함께 기록

이메일·비밀번호를 입력하는 회원가입은 없습니다. 가족 연결을 시작하면 접근 권한 확인을 위한 익명 서버 사용자 식별자를 만듭니다. 보호자가 입력한 표시 이름, 사용자·가족 식별자, 구성원 관계, 초대 비밀의 해시, 만료 시각, 연결 요청과 확인 번호, 생성·변경 시각을 연결·승인·권한 관리에 사용합니다. 이 연결용 정보는 서버에서 처리하며, 아래의 암호화된 육아 기록과 구분됩니다.

아기 프로필과 돌봄 기록, 체중·수유 방식 이력, 일정·완료 상태, 진행 중 타이머, 보호자별 출석·선물 상태를 기기에서 iOS와 호환되는 AES-GCM 형식으로 암호화하여 기존 Supabase 공유 서버에 저장합니다. 기록을 읽는 열쇠는 서버에 저장하지 않고 각 보호자 기기에 보관합니다. 초대 링크의 # 뒤에는 열쇠가 포함되므로 의도한 보호자에게만 전달해 주세요. 운영자는 이 열쇠 없이 원래 기록을 읽거나 복원할 수 없습니다.

기본 구성원은 소유자를 포함해 2명이며, 추가 자리로 최대 4명이 연결됩니다. 초대받은 보호자의 요청을 소유자가 확인 번호로 승인해야 기록을 볼 수 있습니다. 하루 분유 기준량과 개인별 수유·일정·투약 알림 설정, 개인 일기·사진은 가족 공유에 포함하지 않습니다.

공동 기록은 공유를 유지하는 동안 보관합니다. 소유자의 ‘가족 공유 종료’는 서버의 공동 기록과 초대를 삭제합니다. 참여자의 ‘가족에서 나가기’는 본인 접근을 해제하고 소유자의 기록은 유지합니다. 다른 기기에 이미 받은 사본은 회수되지 않습니다. 개별 기록 삭제 후에도 동기화를 위한 삭제 표시·변경 이력이 남을 수 있으므로 서버 공동 기록 전체 삭제는 소유자의 공유 종료로 진행합니다. 초대 링크는 24시간 동안 유효하며, 만료가 관련 정보의 즉시 삭제를 뜻하지는 않습니다.

앱 검토용 체험은 재사용 검토 코드로 여는 별도 테스트 공간입니다. 별도의 익명 식별자와 테스트 서버를 사용하며 일반 기기 기록·운영 가족·구매 권한을 바꾸지 않습니다. 예시 정보만 입력해 주세요. 테스트 공간 안의 설정에서도 서버 연결 정보와 기기 기록을 각각 삭제할 수 있습니다.

3. 비공개 일기와 PDF

일기에는 선택한 사진 최대 3장, 본문 100자, 날짜·날씨·직접 입력한 장소, 배치·글씨체, 표지 이름, 월별 마지막 장 문구·발행 상태·작성 알림을 저장합니다. 일기 작성과 PDF 저장은 무료입니다. 시스템 사진 선택기에서 고른 사진만 가져오며, 다시 저장한 사진에 원본 EXIF 위치 정보를 복사하지 않습니다. GPS·지도 위치를 읽지 않습니다.

일기·사진은 돌봄 기록의 암호화 파일과 별도인 앱 전용 파일에 보관합니다. 운영 서버·가족·워치로 자동 전송하지 않으며 돌봄 기록 JSON 백업과 시스템 백업에도 포함하지 않습니다. 앱 삭제 전 필요한 일기책을 PDF로 보관해 주세요. 직접 저장·공유한 PDF에는 사진과 글이 포함되고 별도 암호가 설정되지 않습니다. 외부 사본은 해당 위치에서 관리·삭제해야 합니다.

4. Google Play 구매

추가 보호자 자리는 일회성 앱 내 구매이며 구독이 아닙니다. 카드 번호·결제 수단·Google 계정 비밀번호는 Google이 처리하고 앱이나 운영자가 받지 않습니다. 구매 검증·승인·복원, 중복 권한 방지 및 취소·환불 반영을 위해 구매 토큰, 상품·주문 식별자, 구매에 연결된 앱 사용자 식별자, 구매·검증 상태와 시각을 Google Play 구매 확인 서비스 및 공유 서버에서 처리합니다. 아기 기록·사진·복호화 열쇠는 구매 검증에 보내지 않습니다.

구매 권한은 공동 기록 소유자에 연결됩니다. 공유 종료나 서버 연결 정보 삭제만으로 구매 확인용 최소 기록을 자동 삭제하지 않으며, 권한 확인·복원·중복 사용 방지에 필요한 동안 별도 보관합니다. 구매 정보 삭제 요청은 본인과 권한 상태를 확인하여 처리합니다. 법령상 보존 의무가 적용되거나 진행 중인 환불·분쟁 확인에 필요한 정보는 해당 사유가 해소될 때까지 보관할 수 있으며, 요청 처리 시 남는 항목과 이유를 안내합니다. 앱 재설치로 서버 사용자가 바뀌면 자동 구매 이전을 보장하지 않습니다. 복원 오류가 나면 반복 결제하지 말고 지원 문의를 이용해 주세요.

5. 알림·푸시와 서비스 로그

가족 연결 또는 연결 요청이 있을 때 Firebase Cloud Messaging(FCM)을 초기화합니다. Firebase 설치 식별자·푸시 토큰, 앱·운영체제·기기 관련 기술 정보가 알림 전달과 서비스 운영에 사용됩니다. 공유 서버에는 푸시 토큰·알림 환경·보호자 기록 알림 수신 선택을 등록합니다. 푸시는 일반적인 새 기록 안내와 동기화 신호이며, 아기 이름·건강 기록·사진·복호화 열쇠를 넣지 않습니다. 연결 해제·서버 연결 정보 삭제 또는 무효 토큰 확인 시 서버 등록을 정리합니다. Google의 설치 정보 처리는 Firebase 개인정보 안내를 따릅니다.

수유 예상·타이머·일정·투약·일기 작성 알림은 기기에 예약합니다. 잠금 화면의 표시 내용과 알림 권한은 기기 설정에서 관리합니다. 알림 시점은 시스템·절전·네트워크 상태에 영향을 받을 수 있습니다.

서버 접속 시 IP 주소, 요청 경로·시각·응답 상태와 기술 로그가 인증·요청 제한·보안·장애 대응을 위해 처리됩니다. 광고나 사용자의 위치 추적에 이용하지 않습니다. 서비스 로그 보관은 제공 업체의 설정 및 보안·법적 보관 기준에 따르며, 모든 로그가 연결 삭제 즉시 지워지는 것은 아닙니다. 관련 정보는 문의처로 요청할 수 있습니다.

6. 음성 입력과 선택 권한

휴대폰 음성 입력은 Android 12 이상에서 한국어 기기 내 인식이 지원되고 준비된 경우에만 사용합니다. 마이크 권한을 요청하며 서버 인식으로 자동 전환하지 않습니다. 지원하지 않거나 권한을 거부해도 직접 입력할 수 있습니다. 앱은 녹음 파일·인식 원문을 보관하지 않고 사용자가 확인하여 저장한 기록만 남깁니다.

Wear OS 음성 입력은 설치된 시스템 음성 서비스를 사용하므로 제공자·설정에 따라 서버에서 처리될 수 있습니다. 기기의 음성 서비스 개인정보 안내와 설정을 확인해 주세요. 알림과 마이크 권한은 Android 설정에서 철회할 수 있습니다. 카메라·위치·연락처·광고 ID 권한은 요청하지 않습니다.

7. 워치·위젯·외부 앱

연결한 Wear OS 워치에는 아기 프로필, 당일 요약, 최근 입력량, 수유 예상·알림 시각 및 전송 상태를 전달합니다. Google Play services의 Wearable Data Layer를 이용하여 기록을 주고받고, 연결되지 않은 동안 대기 기록을 워치에 보관합니다. 개인 일기·사진은 전달하지 않습니다. 워치 기능은 해당 워치 앱을 설치하고 연결한 경우에만 사용합니다.

위젯은 기기에 보관한 아기 이름·생후 일수·수유 요약과 진행 중 활동 등을 홈 화면에 표시합니다. 외부 캘린더 추가는 사용자가 선택한 일정만 전달하며 다른 일정을 읽지 않습니다. 파일 저장·공유·캘린더 추가·지원 메일은 사용자가 선택한 앱에 필요한 내용을 전달하는 기능입니다. 내보낸 사본에는 수신 앱의 개인정보처리방침이 적용됩니다.

8. 처리 업체와 국외 처리

서버 인증·공동 기록 저장·요청 처리에는 Supabase, Inc., Android 푸시에는 Google의 Firebase, 앱 내 구매에는 Google Play를 이용합니다. 공동 기록 데이터베이스의 설정 지역은 대한민국 서울입니다. 제공 업체의 전 세계 접속망·함수·보안·지원 및 하위 처리업체 때문에 모든 처리가 국내에서만 이뤄지지는 않습니다.

Supabase 개인정보 안내 · Supabase 데이터 처리 계약 · Firebase 개인정보 안내 · Google 개인정보처리방침

가족 공유를 선택하지 않아도 기기의 기록·일기 기능을 사용할 수 있습니다. 판매·광고 목적의 개인정보 제공은 하지 않습니다.

9. 보관·삭제와 권리 행사

기기 기록은 사용자가 개별 삭제·모든 기록 삭제·앱 삭제를 할 때까지 보관합니다. 서버 사용자·연결 정보는 연결을 유지하는 동안 보관하고, 설정 또는 함께 기록 화면의 ‘서버 연결 정보 삭제’로 삭제를 요청할 수 있습니다. 본인의 인증 사용자와 연결 관계, 자신이 소유한 공동 기록이 삭제되며 타인이 소유한 기록은 유지합니다. 인터넷 연결이 필요하고 실패 안내가 나오면 완료된 것이 아닙니다.

기기 내 ‘모든 기록 삭제’는 돌봄 기록과 비공개 일기·사진·자동 보관본을 삭제합니다. 공유 중에는 먼저 공유 종료 또는 나가기를 완료해 주세요. 외부 PDF·백업과 다른 기기의 사본은 별도로 확인해야 합니다. 구매 확인용 최소 정보와 제공 업체의 보안·법적 보관 정보는 위 항목에 설명한 예외를 따릅니다.

열람·정정·삭제·처리 관련 문의는 아래 이메일로 접수할 수 있습니다. 앱에 접근할 수 없어도 삭제 요청이 가능합니다. 본인과 삭제 권한을 확인한 뒤 처리하며, 확인에 불필요한 사진·건강 기록·초대 링크·비밀번호·결제 카드 번호를 요구하지 않습니다. 기기에만 있는 일기와 암호화된 기록의 원문은 운영자가 열람하거나 원격 복구할 수 없습니다.
