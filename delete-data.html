기록과 서버 연결 정보 삭제

Android 개인정보처리방침앱 지원

앱을 사용할 수 없어도 요청할 수 있어요.

첫백일+은 이메일·비밀번호 가입 없이 기기에 기록합니다. ‘함께 기록’을 사용한 경우에는 별도의 서버용 익명 사용자와 연결 정보가 생깁니다. 기기 기록과 서버 연결은 아래 방법으로 각각 삭제할 수 있습니다.

이메일로 삭제 요청하기

메일 앱이 열리지 않으면 tomatoto20@outlook.com으로 직접 보내 주세요.

1. 앱에서 서버 연결 정보 삭제

  1. 설정 또는 설정 → 함께 기록에서 서버 연결 정보 삭제를 선택합니다.
  2. 삭제 범위를 확인하고 인터넷에 연결된 상태에서 진행합니다.
  3. 실패 안내가 나오면 삭제 완료가 아니므로 연결을 확인하고 다시 시도합니다.

본인의 서버 인증 사용자·연결 관계와 본인이 소유한 공동 기록이 삭제됩니다. 타인이 소유한 가족 기록은 삭제하지 않습니다. 이미 각 보호자 기기에 받은 사본은 자동 회수되지 않습니다.

2. 기기의 기록·일기·사진 삭제

설정 → 모든 기록 삭제에서 삭제합니다. 가족 공유 중이면 먼저 가족 공유 종료 또는 가족에서 나가기를 완료합니다. 돌봄 기록·아기 프로필·자동 보관본·비공개 일기·사진이 삭제됩니다. 연결한 워치는 다음 동기화 시 확인하며, 오프라인 워치·내보낸 JSON 백업·PDF·외부 캘린더 사본은 해당 기기나 앱에서도 별도로 확인해 주세요. 개별 일기는 날짜별 보기에서 삭제할 수 있습니다.

3. 앱에 접근할 수 없을 때

제목을 ‘첫백일+ 서버 연결 정보 삭제 요청’으로 하여 위 주소에 보내 주세요. Android 사용 여부, 앱에 접근할 수 없는 상황, 삭제하려는 범위(서버 연결·공동 기록·구매 확인 정보 등)를 알려 주세요. 서버용 식별자를 이미 확인할 수 있다면 함께 보낼 수 있으나, 처음부터 민감한 자료를 제출할 필요는 없습니다.

본인과 해당 정보에 대한 권한을 확인한 후 처리 결과를 회신합니다. 다른 보호자의 정보 삭제는 승인 없이 처리하지 않습니다. 아기 사진·건강 기록·초대 링크의 열쇠·비밀번호·전체 카드 번호는 보내지 마세요. 운영자는 기기에만 있는 일기를 직접 삭제하거나 복구할 수 없습니다.

4. 삭제 후 남을 수 있는 정보

구매 복원·중복 권한 방지와 환불 확인에 필요한 최소 구매 확인 정보는 서버 연결 삭제만으로 자동 삭제되지 않습니다. 구매 정보까지 삭제하려면 별도로 요청해 주세요. 법령상 보존 의무나 진행 중인 환불·분쟁 확인에 필요한 정보는 해당 사유가 해소될 때까지 보관할 수 있으며, 처리 시 남는 항목과 사유를 안내합니다. 서비스 제공 업체의 보안·법적 보관 로그와 다른 사람이 이미 저장한 사본도 즉시 회수되지 않습니다. 삭제할 항목과 보관 예외의 상세 내용은 개인정보처리방침에 안내합니다.
